    Alarm buzzer

    An ESP32 with a buzzer sounds in the house when an incident starts. Plug it into this computer with a USB cable, or connect it over Wi-Fi.

    Buzzer

    Anyone signed in can silence it from the Live page, and the BOOT button on the board silences it too. The board's SOS button opens a "help requested" incident.

    Checking the buzzer…

    Find automatically looks for the ESP32's USB chip (CP2102 or CH340) and checks that it runs the HomeShield sketch. Pick a port only if you have more than one board.

    When it sounds

    When an incident starts, and again if it gets worse. It stops once the incident is acknowledged or marked a false alarm.

    Stopping at the time limit only quiets the buzzer: the incident stays open on the dashboard.

    HomeShield IoT 2.1.0

    Final Year Project, IIUM Kulliyyah of ICT.

    HomeShield is a centralized dashboard for real-time CCTV monitoring and machine-learning-powered anomaly detection. One unified pipeline runs three GPU-accelerated detectors on every camera feed, draws bounding-box overlays on the live MJPEG stream, persists every alert to SQLite with an annotated snapshot, and pushes updates to this dashboard via Server-Sent Events.

    Detection stack
    Fall — YOLO11 / YOLO26 pose estimation feeds a 7-state finite-state machine (Standing → Walking → Sitting → Fall_Detected → Lying_After_Fall → Lying_Motionless → Inactivity). Two-stage decision rejects controlled sit-downs.
    Fire — custom YOLO weights covering fire and smoke classes, with per-class cooldown to debounce alerts.
    Face — InsightFace ArcFace (buffalo_l) producing 512-dim embeddings, cosine-matched against the registered people; unknown faces are auto-logged as intruders.
    Zones — polygon zones per camera. Safe zones stop lying-down and no-movement alerts; danger zones raise an incident when a child enters.
    Clips — each incident gets a short H.264 video, starting a few seconds before the first detection, to watch or download from the incident window.
    Alarm buzzer — an ESP32 (CP2102 USB, or Wi-Fi) sounds a different pattern for fire, falls, intruders and danger zones when an incident starts, until someone handles it or presses the board's button. Its SOS button lets someone call for help: a critical incident, WhatsApp alerts, and SOS in Morse code on every buzzer.
